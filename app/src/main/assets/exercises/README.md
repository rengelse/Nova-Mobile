# Offline exercise artwork

Bundled locally with NOVA. 302 exercise illustrations, three SVG frames per exercise (906 SVG files).

Artwork: Workout Guide / Bryl Lim, derived from Everkinetic artwork and distributed under CC BY-SA 4.0.
The vector path assets were sourced from GymMane's bundled offline `assets/art` representation and converted to standalone SVG frames for NOVA.

No runtime network connection is required to display exercise media.
